# Pi Harness 课程

pi coding agent 与 oh-my-pi（omp）的中文互动教程：一页序章、18 课和一页毕业指南。内容核对自 pi 1.1 自带文档；omp 部分对应 18.10。

| 单元 | 课 |
|---|---|
| 序章 | pi 是什么、这门课讲什么、怎么安装 |
| 心智模型 | 1 Harness 是什么 · 2 上下文是预算 |
| 驾驭 pi | 3 第一次会话 · 4 会话是一棵树 · 5 压缩 |
| 配置 | 6 配置的分层与信任 · 7 模型与提供者 |
| 扩展 | 8 指令层 · 9 Skill · 10 扩展 I · 11 扩展 II · 12 MCP、codemode 与包 |
| 边界与自动化 | 13 安全边界 · 14 自动化与嵌入 |
| oh-my-pi | 15 从 pi 到 omp · 16 omp 的工具面 · 17 omp 的编排 · 18 选择与组合 |
| 毕业 | 配好你自己的 pi |

每课的结构：开头说清这一课解决什么问题 → 分节讲解（演示前写明「看什么」）→ 在 pi 里怎么做 → 5 道检查题 → 小结。

打开 `site/index.html` 即可学习。
